# 泡泡玛特直播进销存系统 V2.0

## 🎯 系统架构

### 库存隔离设计
```
主库存（批次管理）──┐
                   │
                   ↓ 复制快照
              直播库存快照
                   │
                   ↓ 直播销售
              销售记录
                   │
                   ↓ 人工操作
              主库存出库
```

## 📊 数据库表结构

### 1. 主库存批次表 `inventory_batches`
- 支持不同进价的批次管理
- 记录每次进货的详细信息
- 支持先进先出（FIFO）出库

### 2. 直播库存快照表 `live_inventory`
- 直播开始时从主库存复制
- 直播期间独立管理
- 不影响主库存

### 3. 出库记录表 `outbound_log`
- 记录手动出库操作
- 支持关联直播场次
- 支持订单号追踪

## 🚀 使用流程

### 1. 初始化数据库
```bash
# 执行数据库迁移
mysql -u ppmart -p ppmart < database_v2_batch_system.sql
```

### 2. 日常操作

#### 采购入库
1. 进入【商品管理】
2. 点击"入库"按钮
3. 填写进价、数量、供应商等信息
4. 系统自动生成批次号（如：B202604301530001234）

#### 创建直播
1. 进入【直播场次】
2. 点击"创建新场次"
3. 输入场次名称
4. 点击"🎬 开始直播"
5. 系统自动复制当前主库存作为直播库存快照

#### 直播销售
1. 扫描商品条码
2. 显示直播库存和价格
3. 点击或按数字键减库存
4. 中键或Shift+数字键退还库存
5. 退还数量不能超过已售数量

#### 手动出库
1. 直播结束后
2. 出库人员在主库存操作出库
3. 支持先进先出（FIFO）
4. 可关联直播场次和订单号

## 📺 直播界面操作

### 快捷键
| 按键 | 功能 |
|------|------|
| 1/2/3/4 | 减对应状态库存 |
| Shift + 1/2/3/4 | 加对应状态库存（退还） |
| Q/W/E/R | 修改对应状态价格 |
| Space | 关闭当前商品 |
| Esc | 取消/返回 |

### 鼠标操作
- 左键点击：减库存
- 中键点击：加库存（退还）

## 🔧 API 接口

### 直播相关
- `scan_product_live.php` - 扫描商品（从直播库存）
- `sell_product_live.php` - 直播销售
- `return_product_live.php` - 直播退还
- `copy_inventory_to_live.php` - 复制库存快照

### 主库存相关
- `purchase_batch.php` - 批次入库
- `outbound_batch.php` - 批次出库（FIFO）

## ⚠️ 重要提示

1. **库存隔离**：直播库存是主库存的快照，直播销售不影响主库存
2. **退还限制**：退还数量不能超过已售数量
3. **批次管理**：每次入库生成独立批次，支持不同进价
4. **先进先出**：出库时按入库时间顺序扣减批次

## 📈 数据统计

- 每场直播独立统计销售额
- 支持按场次查看销售报表
- 支持批次成本核算
